# The Learn Vista (TLV)

Fresh Version 1 static website for GitHub Pages.

## Included
- Responsive premium landing page
- TLV logo
- Learning/resource search and filters
- Exam hub with search/filter
- Scholarship discovery section
- Academic Events and General Events, each with photo/video folders
- Announcements / updates
- Interactive study dashboard UI
- FAQ
- Contact/social links
- Respectful TLV-branded loading interface
- No Supabase or backend dependency
